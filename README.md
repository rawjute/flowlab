# FlowLab

Editor ed esecutore di **diagrammi di flusso** per la didattica, in italiano.

**Usalo online:** https://rawjute.github.io/flowlab/

Tutto il programma è un unico file (`index.html`): niente login, niente server, niente installazioni. Si può anche scaricare e aprire con un doppio clic, pure senza internet.

## Funzioni

- Blocchi: Dichiara, Assegna, Leggi, Scrivi, Se, Mentre, Fai… mentre, Per, Commento
- Inserimento con i **+** sulle frecce, modifica con doppio clic, spostamento trascinando, annulla/ripeti
- Esecuzione completa o **passo passo**, con evidenziazione del blocco attivo e tabella delle variabili
- Messaggi di errore in italiano pensati per gli studenti (il blocco che sbaglia diventa rosso)
- Tipi Intero, Reale, Stringa, Booleano e vettori
- **Copia immagine** negli appunti, download PNG/SVG (anche in bianco e nero per la stampa)
- Traduzione automatica in **C++, Python, Java e pseudocodice**
- Salvataggio automatico nel browser e su file (`.json`)
- Programmi di esempio e guida integrata
